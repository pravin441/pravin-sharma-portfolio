About Me

I'm a third-year BCA student at SDJ International College in Surat, with a focus on full-stack web development. I work across the MERN stack: React for the interface, Node.js and Express.js for the server and REST APIs, and MongoDB for data.

My main project, StudySphere, is a platform where students and teachers manage assignments, deadlines and submissions in one place. I also completed a five-week remote Full Stack Developer internship at Civora Nexus, where I worked on a QR-based authentication system, used Git and GitHub daily, and applied mentor feedback to project modules.

I like breaking a feature down into its interface, API and data layers, and I'm currently exploring AI and mobile application development to widen what I can build.
